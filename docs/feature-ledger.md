Publisher app listings describe features beyond the observed web flow. No native binary was supplied for analysis, so mobile-app behavior is publisher-reported rather than runtime-verified.

## Correction and pending parity

An earlier 50-round replay used 614 spelling answers; it is superseded and does not establish meaningful recognition. The corrected featured-profile oracle recovered 128/128, with zero wrong/unresolved and at most ten questions; this is closed-world testing, not human accuracy. No private Limule reconstruction or native-app parity is claimed. Publisher-only mobile features and any unverified cloud flow remain pending rather than silently counted as implemented parity.

## Reference contribution workflows still pending

The publisher describes duplicate suggestions, moderated name refinements, character additions after failed guesses, question duplicate checks and photo permissions. Our local proposal export plus manual source review covers submission preparation, not an automated shared comparison or moderation system. Duplicate-proposal comparisons and guess-name refinements remain pending. Account email delivery/setup must be verified separately; do not represent unfinished mail configuration as working email authentication.
