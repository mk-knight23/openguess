# Feature ledger

| Capability               | OpenGuess 0.2 scope                                                     | Boundary                                                       |
| ------------------------ | ----------------------------------------------------------------------- | -------------------------------------------------------------- |
| Adaptive guessing        | Five answers, correction, undo, rejection, explanations                 | Original heuristic engine, not Limule recovery                 |
| Multiple themes          | People, fiction, mammals, object types, films                           | Finite packs with sparse facts and name fallback               |
| Replay goals             | Five daily discoveries/theme, local awards, collection, points, streaks | Local editable progress; pack updates can alter challenges     |
| Languages                | 18 partial interface languages                                          | Questions and data remain English                              |
| Profiles and portability | Local nickname/settings, validated JSON backup                          | Browser storage can be cleared                                 |
| Accounts and cloud       | Optional configured Supabase account/backup/public wins                 | Opt-in, live verification separate; wins not competition-grade |
| Contributions            | Character/question/photo JSON proposals                                 | Manual review; no automatic global learning                    |
| Content controls         | Family preference/filter boundary                                       | No age verification or parental account                        |
| Ads and premium unlocks  | Intentionally absent                                                    | Free gameplay and open-source software                         |
| Reference parity         | Genre-informed original game                                            | Exact worldwide/native-app parity not claimed                  |

Publisher app listings describe features beyond the observed web flow. No native binary was supplied for analysis, so mobile-app behavior is publisher-reported rather than runtime-verified.
