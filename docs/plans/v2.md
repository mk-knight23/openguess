# OpenGuess 0.2 upgrade

2026-10-14. User authorized research, implementation, public GitHub push and live deployment.

## Outcome

Thousands of real entities per theme: people, fictional characters, animals, objects and films; no fabricated padding. Import CC0 Wikidata structured facts with entity IDs, retrieval time, provenance and measurable missing/duplicate-trait coverage. The database is a local versioned pack, not scraped Akinator data.

Expand gameplay with theme selection, daily challenge, achievements/collection, local profile and portable progress, recent guesses, corrected answers, community character/question/photo proposals, sensitive-content controls and language settings. Clearly identify local-only features and do not pretend to have worldwide shared rankings/accounts. Preserve free gameplay. Track any unavailable reference behavior in a feature ledger.

Use actual REA browser observations for the reference site and browser-scoped tools relevant to the question. Create original OpenGuess artwork/animations in a genie-game visual direction. Never copy proprietary art, scripts or data. Capture exact observation limits.

## Implementation

1. Re-investigate live reference site, scripted gameplay transitions and publisher app feature inventory.
2. Data importer and data-quality tests first; acquire >=1000 distinct sourced entities per theme with useful semantic traits. Lazy-load packs and keep static assets small.
3. Optimize inference for large catalogs, handle missing facts and tied candidates honestly, test cross-theme ranking and responsiveness.
4. Implement expanded local features with test-first state module and explicit import/export validation.
5. Original animated blue/gold genie-game interface and accessible mobile/desktop layouts. Integrate lazy loading, settings, profiles, collection, challenge and contributions.
6. Benchmark every pack, test real browser journeys and accessibility. Review spec and code independently, fix defects.
7. Push a review branch/PR, publish approved reviewed code on main, deploy and verify actual live gameplay. Record provenance, research, feature coverage, known gaps and learnings.

## Constraints

No pricing/ads/paid AI. No credentials embedded. Do not ship thousands of indistinguishable names as if they were good gameplay data. Unknown properties remain unknown. New global services require explicit provisioning; local substitutes are visibly local and never called global. Node24 baseline, MIT application code, CC0 imported structured data with provenance, separate font/dependency notices.
